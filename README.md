# ระบบสารสนเทศการปฏิบัติวิปัสสนากรรมฐาน มหาวิทยาลัยมหาจุฬาลงกรณราชวิทยาลัย (VPSMCU)
**Mahachulalongkornrajavidyalaya University Vipassana Meditation Information System**

ระบบบริหารจัดการและประมวลผลข้อมูลการปฏิบัติวิปัสสนากรรมฐานของมหาวิทยาลัยมหาจุฬาลงกรณราชวิทยาลัย ครอบคลุม 51 ส่วนงานทั่วประเทศ (วิทยาเขต, วิทยาลัยสงฆ์, ส่วนกลาง และหน่วยวิทยบริการ) พัฒนาบนพื้นฐานของ **Laravel 11, PHP 8.4, MariaDB 10.6, Apache 2.4, และ Tailwind CSS (Blade Views)** เพื่อรองรับการติดตั้งบนโครงสร้างพื้นฐานโฮสติ้งของมหาวิทยาลัยโดยเฉพาะ

---

## 🏛️ สถาปัตยกรรมระบบ (Architecture & Tech Stack)

- **Backend Framework:** Laravel 11.x (PHP 8.4.8)
- **Web Server:** Apache 2.4.63
- **Database:** MariaDB 10.6.21
- **File Upload Capacity:** รองรับไฟล์เอกสาร/รูปภาพสูงสุด **50 MB** (`upload_max_filesize = 50M`, `post_max_size = 50M`)
- **Frontend / Styling:** Blade Views, Tailwind CSS, ฟอนต์ Sarabun / Prompt / Inter
- **Design System:** Earth Tones / Organic Palette (เขียวมะกอก `#5A6B47`, เขียวป่าลึก `#2C3E2D`, ดินเผา `#C86D51`, ทราย/หินอ่อน `#F7F5EE`, เปลือกไม้ `#4A3B32`)
- **Icon System:** [Lucide Icons](https://lucide.dev/icons/) 100% (ห้ามใช้อิโมจิใน Functional UI)
- **Charts & Visualizations:** Chart.js 4.x
- **Containerization:** Podman Rootless & SELinux Compatible

---

## ⚡️ เริ่มต้นใช้งานผ่าน Podman (Quick Start)
 
ระบบพร้อมรันทันทีผ่าน Podman Compose:
 
1. **เริ่มระบบ (Start Containers):**
    ```bash
    podman-compose up -d
    ```
 
2. **การเข้าถึงระบบผ่านเบราว์เซอร์:**
    - **หน้าบ้าน (Portal):** [http://localhost:8086/](http://localhost:8086/)
    - **หน้าเข้าสู่ระบบหลังบ้าน (Admin Login):** [http://localhost:8086/login.php](http://localhost:8086/login.php)
    - **ฐานข้อมูล (phpMyAdmin GUI):** [http://localhost:8088/](http://localhost:8088/)
 
3. **ข้อมูลบัญชีผู้ใช้ระบบหลังบ้าน (Default Credentials):**
    *(รหัสผ่านทุกบัญชีคือ `password`)*
    - **Super Admin:** ผู้ใช้ `admin`
    - **เจ้าหน้าที่ส่วนกลาง (Central Officer):** ผู้ใช้ `central`
    - **เจ้าหน้าที่วิทยาเขตเชียงใหม่:** ผู้ใช้ `officer_cmi`
    - **เจ้าหน้าที่วิทยาเขตขอนแก่น:** ผู้ใช้ `officer_kkn`

## 📦 โมดูลการทำงานหลัก (Core Business Modules)
 
### 1. โมดูลระดับปริญญาตรี (Undergraduate - 10 วัน/ปี รวม 40 วัน)
- **ระบบหน้าบ้าน (Portal):**
  - **แท็บเมนูสลับหน้าจอ (Tab Navigation):**
    1. **ลงทะเบียนเข้าร่วม (`/ug_register.php` / `/ug/register`):** เลือกรอบโครงการ กรอกรหัสนิสิตเพื่อตรวจสอบสิทธิ์อัตโนมัติ
    2. **ตรวจสอบข้อมูลและบัตรประจำตัว (`/ug_check.php` / `/ug/check`):** ค้นหาด้วยรหัสนิสิต (10 หลัก) หรือรหัสการสมัคร (`UG-...`)
  - **Campus-Binding Rule:** ตรวจสอบสังกัดวิทยาเขตอัตโนมัติ กรองให้นิสิตลงทะเบียนเฉพาะโครงการของวิทยาเขตต้นสังกัดเท่านั้น
  - **E-Pass Modal & Print:** ป๊อปอัปบัตรประจำตัวพร้อม QR Code สำหรับสแกนหน้างาน และพิมพ์บัตร (A4 / E-Ticket Pass)
  - **Digital Certificate Link:** ตรวจสอบและดาวน์โหลดวุฒิบัตรอิเล็กทรอนิกส์เมื่อผ่านการอบรม
- **ระบบหลังบ้าน (Admin Console):**
  - จัดการกำหนดการโครงการปฏิบัติธรรมประจำปีการศึกษา (`UgBatch`)
  - ระบบนำเข้าข้อมูลนิสิตผ่านไฟล์ CSV พร้อมระบบตรวจสอบความถูกต้อง (`/admin/ug_import.php`)
  - ระบบสแกน QR Code เช็คชื่อหน้างานผ่านมือถือ (Mobile Scanner - `/admin/ug_scanner.php`)
  - ระบบพิมพ์ใบเซ็นชื่อ A4 Print-ready 10 วัน (`/admin/ug_attendance.php`)
  - ส่งออกข้อมูลทะเบียนนิสิตเป็นไฟล์ CSV/Excel พร้อม UTF-8 BOM (`/admin/ug/export`)
 
### 2. โมดูลระดับบัณฑิตศึกษา (Graduate Studies - ป.โท 30 วัน / ป.เอก 45 วัน)
ระบบครบวงจรแบบ **Paperless e-Document Workflow** ทั้งหน้าบ้านและหลังบ้าน:
- **หน้าบ้าน (Portal):**
  - **แท็บเมนูสลับหน้าจอ (Tab Navigation):**
    1. **ยื่นคำร้อง e-Document (`/grad_request` / `/grad/request` / `/graduate`):** หน้าเริ่มต้นสำหรับยื่นเอกสารขออนุมัติ แบบฟอร์ม 4 ส่วน พร้อมแนบหลักฐานสำคัญ 4 รายการ:
       - รูปถ่ายหน้าตรงขนาด 2x2 นิ้ว (JPG/PNG)
       - ใบบันทึกสอบอารมณ์ฉบับสมบูรณ์ (PDF)
       - ใบลงเวลาปฏิบัติธรรม (PDF)
       - สลิปหลักฐานการชำระเงินค่าธรรมเนียมพร้อมระบุวันเวลาที่โอนเงิน
    2. **ตรวจประวัติสะสมวัน (`/grad_progress.php` / `/grad_progress`):** ค้นหาด้วยรหัสนิสิต ตรวจสอบวันสะสม ประวัติการปฏิบัติธรรมย่อย กราฟิกแสดงความคืบหน้า และดาวน์โหลดเอกสารเมื่อผ่านการอนุมัติ
  - **Lock Engine:** ไม่อนุญาตให้ยื่นขออนุมัติหากสะสมวันไม่ครบตามเกณฑ์ (ป.โท < 30 วัน, ป.เอก < 45 วัน) และล็อกห้ามแก้ไขรายการเมื่อสถานะเป็น `SUBMITTED`
  - **Dual-Language Switch:** รองรับการสลับภาษาไทย (TH) และอังกฤษ (EN) สะดวกครบถ้วน
- **หลังบ้าน (Admin Console):**
  - **ตรวจสอบคำขออนุมัติ (`/admin/grad_approvals.php`):**
    - ระบบค้นหาละเอียด 9 มิติ (9-Dimension Search & Filtering)
    - ระบบจัดการแบบกลุ่ม (Bulk Actions: อนุมัติกลุ่ม, ส่งกลับแก้ไขกลุ่ม)
    - ระบบเปิด-ปิดรับคำร้อง e-Document แบบ Toggle Switch
    - คอลัมน์แสดงหลักฐานพร้อมลิงก์ตรวจสอบ: `1. สอบอารมณ์`, `2. ใบลงเวลา`, สลิปโอนเงิน (Compact Icon พร้อม Tooltip วันเวลา)
    - Modal แก้ไขข้อมูลนิสิตครบวงจร: แอดมินสามารถแก้ไขข้อมูลส่วนตัว ที่อยู่ วุฒิการศึกษา และอัปโหลดแทนที่ไฟล์แนบทั้ง 4 รายการได้ทันที
    - Modal พิจารณาอนุมัติพร้อมอัปโหลดเอกสารตอบกลับ 4 รายการ (ใบรับรองภาษาไทย, ใบรับรองภาษาอังกฤษ, ใบเสร็จรับเงิน, เอกสาร บฑ.๒๑)
  - **ทะเบียนนิสิตบัณฑิตศึกษา (`/admin/grad_students.php`):** ทะเบียนประวัตินิสิตทั้งหมดและการสะสมวัน
  - **สถิติบัณฑิตศึกษา (`/admin/grad_sar.php`):** รายงานสถิติผลการดำเนินงานระดับบัณฑิตศึกษาจำแนกตามส่วนงาน 51 แห่งทั่วประเทศ
 
### 3. โมดูลบริการวิชาการแก่สังคม (Public Meditation Community)
- **ระบบหน้าบ้าน (Portal):**
  - **แท็บเมนูสลับหน้าจอ (Tab Navigation):**
    1. **สมัครเข้าร่วมโครงการ (`/public_register.php` / `/public/register`):** ฟอร์มลงทะเบียนประชาชนทั่วไป เลือกรอบโครงการ ระบุข้อมูลส่วนบุคคล ที่อยู่ ข้อมูลติดต่อฉุกเฉิน และโรคประจำตัว
    2. **ตรวจสอบข้อมูลการสมัคร (`/public_check.php` / `/public/check`):** ตรวจสอบสถานะการลงทะเบียน คิวสำรอง และดาวน์โหลดใบคอนเฟิร์ม
  - **Phone-Based Quick Search (ไม่ต้องใช้เลขบัตรประชาชน/พาสปอร์ต):**
    - ค้นหาได้สะดวกรวดเร็วด้วย **หมายเลขโทรศัพท์ (ไม่ต้องใส่เครื่องหมายขีด `-` เช่น `0818889999`)** หรือรหัสการสมัคร (`PUB-...`)
    - ระบบทำ Sanitization ตัวเลขโทรศัพท์อัตโนมัติ ตัดช่องว่างและขีดออกทั้งหมด
  - **Registration Slip Modal & Print:** แสดงข้อมูลโครงการ สถานะการยืนยัน วันที่รายงานตัว พร้อมปุ่มพิมพ์ใบยืนยันการสมัคร
- **ระบบหลังบ้าน (Admin Console):**
  - จัดการโครงการปฏิบัติธรรมประชาชน จัดการคิวรับสมัคร และการยืนยันที่นั่ง
  - ระบบทะเบียนและพิมพ์บัตรประจำตัวผู้เข้าร่วม
  - รายงานสถิติและผลการดำเนินงานระดับชาติจำแนกตามส่วนงาน
 
### 4. ระบบสถิติ แดชบอร์ด และการวิเคราะห์ข้อมูล
- **Admin Dashboard (`/admin/dashboard.php`):** การ์ดสรุป KPI สถิติกราฟแท่ง (Bar Chart) จำแนกรายส่วนงาน เปรียบเทียบ 3 กลุ่มเป้าหมาย (ป.ตรี, บัณฑิตศึกษา, บริการวิชาการ) พร้อมตารางสรุป
- **สถิติบัณฑิตศึกษา (`/admin/grad_sar.php`):** รายงานตัวชี้วัดผลสัมฤทธิ์บัณฑิตศึกษาจำแนกรายส่วนงาน
- **Executive Analytics (`/admin/executive_analytics.php`):** ระบบวิเคราะห์เปรียบเทียบเชิงลึกระหว่างส่วนงานสำหรับผู้บริหาร
 
### 5. ระบบข่าวสารและติดต่อสอบถาม
- **ข่าวสารประชาสัมพันธ์ (`/admin/news.php` / `/news.php` / `/news_detail.php`):**
  - จัดการข่าว ปักหมุด กรองหมวดหมู่ บันทึกยอดวิว และแชร์ลิงก์
  - **ระบบคลังภาพกิจกรรม (Photo Gallery):** อัปโหลดภาพกิจกรรมได้พร้อมกันหลายไฟล์ (`gallery_files[]`) หรือใส่ URL หลายรายการ พร้อมจัดการลบภาพเดิมได้สะดวก
  - **แสดงผลภาพแบบเต็มสัดส่วน (Full Display / ไม่ตัด 1:1):** แสดงภาพหน้าปกและภาพประกอบข่าวแบบ `object-contain` ครบถ้วน ไม่ตัดขอบ และมีระบบ **Lightbox Modal** คลิกขยายดูภาพขนาดใหญ่เต็มหน้าจอ
- **ติดต่อสอบถาม (`/contact.php` / `/admin/contact_settings.php`):** ฟอร์มรับข้อความหน้าบ้าน และระบบตั้งค่าข้อมูลติดต่อ/กล่องข้อความหลังบ้าน
 
### 6. ระบบรับบริจาคและการเงิน (Donations & Fund Management)
- **หน้าบ้าน (Portal - `/donation.php`):** บัญชีธนาคาร มจร และ พร้อมเพย์ e-Donation, แบบฟอร์มแจ้งการบริจาค (ชื่อ-นามสกุล, ติ๊กเลือกลดหย่อนภาษี, เลขประจำตัวผู้เสียภาษี 13 หลัก, จำนวนเงิน, วันที่-เวลาโอน, แนบสลิป JPG/PNG/PDF), รายนามผู้ร่วมบุญและสถิติเรียลไทม์
- **หลังบ้าน (Admin Console - `/admin/donations.php`):** สรุปสถิติยอดเงินรวม/รอตรวจสอบ/ลดหย่อนภาษี, กราฟแนวโน้มรายเดือน (Chart.js), หน้าต่างตรวจสอบสลิป, อัปเดตสถานะยืนยันการบริจาค, ตั้งค่าบัญชีธนาคาร, ส่งออก Excel/CSV
